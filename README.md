# 🏦 Bank Management System in C

A console-based Bank Management System developed using the C programming language. This is my first GitHub project, created as part of my journey into programming and software development.

## 📌 About the Project

The Bank Management System is designed to demonstrate basic C programming concepts through a banking-related application. It provides a menu-driven console interface for interacting with the program.

## 🛠️ Technologies Used

* **Language:** C
* **Compiler:** GCC / Turbo C++ (depending on compatibility)
* **Development Environment:** VS Code / Turbo C++

## ✨ Features

The program demonstrates banking operations through a console interface. The available operations depend on the implementation in the source code.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `MyFirstProject.c` in a C editor or IDE.
3. Compile the source code using a compatible C compiler.
4. Run the compiled program in your terminal.

### Compile using GCC

```bash
gcc MyFirstProject.c -o Bank
```

### Run on Windows

```bash
Bank.exe
```
